# リファレンス

> SKILL.md から参照される追加情報です。
> 必要に応じて Claude が読み込みます（Progressive Disclosure）。

## 詳細仕様

### 入力形式

| フィールド | 型 | 必須 | 説明 |
|------------|-----|------|------|
| field1 | string | ✓ | 説明 |
| field2 | number | - | 説明 |

### 出力形式

```json
{
  "result": "処理結果",
  "status": "success"
}
```

## エラーコード

| コード | 説明 | 対処法 |
|--------|------|--------|
| E001 | 入力ファイルが見つからない | パスを確認 |
| E002 | フォーマットエラー | 入力形式を確認 |

## 制限事項

| 項目 | 制限 |
|------|------|
| 最大ファイルサイズ | 10MB |
| サポートエンコーディング | UTF-8 |
